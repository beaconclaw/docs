---
title: "Alerts"
description: "Where alerts go and what raises them."
---

An alert needs two things: a **channel**, which is where it is sent, and a **rule**, which says what raises it and for which agents.

## Channels

| Kind | Needs |
| --- | --- |
| Discord | An incoming webhook address |
| Slack | An incoming webhook address |
| Email | Up to ten addresses |

A channel has a **Send test** button. Webhook addresses are stored encrypted and are not shown again.

## Rules

| Rule | Raised when |
| --- | --- |
| Goes offline, and comes back | An agent stops reporting, and again when it returns |
| Memory or disk stays high | It stays at or above a percentage for a number of minutes |
| A part of the runtime keeps failing | A check, such as a chat channel, fails for a number of minutes |
| Daily summary | Once a day, one message covering every agent |

A rule applies to one agent or to every agent in the organization.

A rule or a channel can be turned off without deleting it. Nothing is sent through one that is off.

## Who can set them up

Owners and admins manage every channel and rule. A steward or operator can add channels of their own and rules for the agents they are assigned to.

## Maintenance

While an agent is in maintenance its alerts are held back. When the window ends, those that are still true are sent.

## Messages to you alone

Alert rules send to shared channels. Separately, each person chooses what they are told about each agent, under **Notifications** in the menu under their email:

- going offline and coming back
- a health problem, and when it clears
- maintenance starting or ending
- a version changing

Each can go to your email address, to a Slack direct message, or both. Slack direct messages need the organization to connect its own Slack app on the Alerts page.

Nobody is messaged because of their role. Someone newly assigned as an operator starts with outages by email and can change it; everyone else starts with nothing. You can only be told about an agent whose full page you can open.

## History

The Alerts page lists the last alerts raised, each with where it was sent and whether it arrived. An agent's own page lists the alerts raised about it.

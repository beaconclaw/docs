BeaconClaw is fleet infrastructure for self-hosted AI agents: tools for the agent that runs your agents, and the full view for your team.

- **Your supervising agent** gets an API and an MCP server to see every agent, find out what is failing, and bring it back, within limits each machine sets.
- **Your team** gets the record in the app: what each agent does, what it connects to, how healthy it has been, and who answers for it.

A small open-source CLI runs beside each agent and reports over an outbound connection. Nothing connects in to the machine. It supports [OpenClaw](https://github.com/openclaw/openclaw) and [Hermes Agent](https://github.com/NousResearch/hermes-agent).

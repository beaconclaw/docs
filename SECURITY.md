# Security

This repository holds the documentation site. To report a security problem in
BeaconClaw itself, or in this site, please do it privately, not in a public
issue or pull request.

Use **Report a vulnerability** on this repository's
[Security tab](https://github.com/beaconclaw/docs/security/advisories/new),
or on the [agent's repository](https://github.com/beaconclaw/beaconclaw/security/advisories/new)
if it concerns the agent. That opens a private report only the maintainers can
see. You will get a reply within a few working days.
